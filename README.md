Bem-vindo ao repositório do projeto Ebac Shoes! Este projeto é uma loja de tênis desenvolvida para fins educativos, utilizando HTML, CSS, JavaScript e a biblioteca jQuery. 
O objetivo é proporcionar uma experiência de aprendizado prático no desenvolvimento web.

📦 Sobre o Projet
]### 📦 Sobre o Projeto
O Ebac Shoes é uma loja online que permite aos usuários navegar por uma variedade de tênis, visualizar detalhes dos produtos e simular uma experiência de compra. 
O projeto está em desenvolvimento e será atualizado com novas funcionalidades e melhorias ao longo do tempo.

### 🚀 Tecnologias Utilizadas
HTML: Estruturação do conteúdo da página
CSS: Estilização e layout da loja
JvaScript: Interatividade e manipulação do DOM.
jQuery: Facilita a mnipulação de elementos HTML e a implementação de animações.

### 🛠️ Funcionalidades Planejadas
Exibição de uma lista de produtos (Tênis).
Detalhes do produto
